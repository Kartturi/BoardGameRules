# Task 4: RAG Engine & Vector Store Module

## Objective
Implement the standalone RAG module responsible for chunking rulebooks, storing vector embeddings, and answering rule questions.

## Requirements
- Implement PDF text extraction and semantic/section-aware rulebook chunking.
- Integrate the vector database client to index rulebook chunks with game metadata and page references.
- Implement semantic search and RAG question-answering over an indexed game's rulebook.
- Add unit tests for chunking, indexing, retrieval, and question answering.
