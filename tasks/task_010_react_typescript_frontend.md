# Task 10: React & TypeScript Frontend UI

## Objective
Build a clean, intuitive React + TypeScript web interface for browsing game rules, generating Quick Recaps, asking rule questions, and viewing saved history.

## Requirements
- Implement Google Sign-In screen and authenticated session handling.
- Create the Game Selector & Rule Reader view with a "Quick Recap" button.
- Create the interactive RAG Q&A input where users ask specific questions about the game's rulebook.
- Add "Save" actions on rules, recaps, and Q&A answers, plus a "Saved History" view for the logged-in user.
